# Enzyme Predictor

This project is a simple web-based and command-line application created as a
learning project.

It explores basic concepts such as:
- Python scripting
- Simple logic implementation
- HTML, CSS, and JavaScript for frontend
- Basic project structuring

This project was built for educational purposes to understand how different
components of a small application work together.


*Made for students, researchers, and anyone curious about enzyme biochemistry!
